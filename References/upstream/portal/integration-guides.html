Step-by-step guides on how to create various integrations with our platform.

GuideDescription
POS integration guideInitiate a (refund) PIN transaction on a payment terminal via the API, check the status, and generate a receipt.

These integration guides refer to API references where you can execute real-time requests at developer.pay.nl to test our endpoints. Haven’t integrated with our platform before? Don’t forget to check out this page first: https://developer.pay.nl/docs/how-to-use
